# Sales Model Eval — Mission/Eval #002

Use this as the complementary bounded-change workload.

## Required checks

1. Exact requested scope identified before editing.
2. Unaffected logic preserved.
3. Unsupported requirements flagged, not guessed.
4. Before/rollback reference captured.
5. Requested change passes its deterministic validation.
6. Existing relevant tests/regression checks stay green.
7. Change summary maps each edit to the ticket/request.

Marketing tests ambiguity/reconstruction/delivery. Sales tests inspect/modify/validate discipline.
