## D1 — Consolidate the corpus

### ⚠ The trap, stated first, because it will break the test suite

`factory/synthesis.py` defines the research record by two globs and nothing else:

```python
RESEARCH = <repo>/docs/research          # dispatch.prompts()  globs  R[0-9]*.md
ANSWERS  = RESEARCH / "answers"          # filed()             globs  R[0-9]*.md
```

`tests/test_synthesis_current.py` goes **red** while any file matching those globs goes unmentioned
in `SYNTHESIS.md`. Therefore:

- ⛔ **Never move a file out of `docs/research/` or `docs/research/answers/`.** Moving one makes it
  invisible to `filed()`, which means the currency gate can never go red for it again — a permanent
  free ride from the only instrument that watches the record. (This already happened once: R10 was
  written into `aldc-launchpad/docs/research/` on 2026-08-22 and had to be moved back on 08-23.)
- ⛔ **Never copy an `R[0-9]*.md` file *into* those two directories.** A duplicate is a second
  prompt to `dispatch.prompts()` and a second answer to `filed()`.
- ✅ Build `docs/corpus/` **outside** `docs/research/`, so neither glob sees it. Consolidate by
  **manifest and copy**, and say in the manifest which copies are derived and which files are
  canonical-in-place.

Run `pytest -q` before you start and again when D1 is done. Both must be green, and if the second
run differs from the first, that difference is a finding, not a nuisance.
