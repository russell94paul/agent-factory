UNMEASURABLE is not a pass. A gate with no instrument says so rather than waving through; that distinction is the point of the whole harness.

Every row is measured from a file at the moment shown above and names the path it came from. Nothing here is hand-maintained, so a wrong row means a wrong repo, not a stale page. Probes live in factory/readiness.py.

The work list is the gate list. Every gate that is not passing is a task, and a gate that passes stops being one. There is no second list to keep in sync, so the board cannot describe work nobody measures or omit work somebody does. The only authored part is which task must precede which, and a stale edge fails on import.
