# Deep Research Prompt 03 — Agent Phenotypes / Human & Nature Inspired Configuration

You are exploring whether Agent Factory can produce meaningfully differentiated agent behavior using configuration inspired by human cognition, expertise, organizations, biological systems and adaptive systems.

## Goal

Build a rigorous **Agent Phenotype Ontology**.

Do not create decorative personalities.

Every proposed trait must map to:
1. a software mechanism;
2. observable behavior;
3. a measurable outcome;
4. an experiment.
