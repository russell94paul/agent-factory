## Goal

Create remote-company presence and culture without requiring the social layer to justify itself with productivity ROI.

The work layer should be rigorous. The social layer can be delightfully unnecessary.

## Human + agent shared-world features

### Agent Office Hours
Expert agents appear in scheduled rooms.

### Tour Guide Agent
Walks new employees through systems, teams, projects, and knowledge.

### Spectator Mode
Observe major agent operations without opening every transcript.

### Persistent Coworker Memory
An agent can recognize a returning user and summarize what changed since the last interaction.

## Gamification principles

Good:
- verified improvement,
- cross-team contributions,
- learning reuse,
- finding preventable recurrence,
- helpful knowledge contribution,
- successful collaboration,
- cheap informative experiments.

Bad:
- message-count leaderboards,
- token-count rewards,
- raw task-count rewards,
- agent-count rewards,
- unsafe speed incentives,
- popularity contests,
- public ranking that maps accidentally to authority.

## Humor style

Self-aware, dry, slightly dramatic.

Examples:
- “Recon has discovered the problem. It was an environment variable. Again.”
- “Command authorization denied. Production remains safe from everybody involved.”
- “All objectives achieved. Nobody touch it.”
- “HAMMER-4 has encountered undocumented vendor behaviour and would like somebody else to suffer with it.”
