# 10 — Agentic Research Program

## Research objective

Determine which concepts genuinely outperform traditional UI/agent orchestration and which are merely visually appealing.

## Research organization

Possible research force:
- Research Commander
- Human-Swarm/HCI Scholar
- Agent Systems Analyst
- RTS/Game Interaction Pattern Miner
- Organizational Science Analyst
- UI Recon Agent
- Red Cell / Skeptic
- Benchmark Designer
- Architecture Mapper
- Synthesis Officer

## High-priority research themes

### RUX-01 — Human-Swarm Command Vocabulary
How can one human command 10 / 50 / 100+ agents without attention scaling linearly?

Study:
- macro vs micro control,
- hierarchical control,
- group selection,
- task delegation,
- autonomy allocation.

### RUX-02 — Spatial Command vs Conventional Navigation
For which tasks does spatial location reduce search/navigation time?

### RUX-03 — Mixed Initiative
When should the system act, prepare, suggest, ask, wait, or escalate?

### RUX-04 — Ecological Interface Design
Which deep system constraints can be made visually perceptible so operators can diagnose novel states?

### RUX-05 — Context as Logistics
Can missing/stale/incorrect context be treated like a measurable supply problem?

### RUX-06 — Collision Detection
How should the system detect semantic duplicate work, conflicting assumptions, and organizational resource collisions?

### RUX-07 — Formation Discovery
Mine mission traces to discover whether successful organizations cluster into recurring team/workflow topologies.

### RUX-08 — Gamification Without Goodhart
Which rewards improve participation and learning without rewarding activity spam or unsafe behaviour?

### RUX-09 — Recurring Failure Intelligence
Develop robust failure-family classification, recurrence detection, and learning-chain diagnostics.

### RUX-10 — Advanced Projects Command
Can an autonomous organization identify higher-leverage improvements than a standard backlog/research process?

### RUX-11 — World vs Dense UI Allocation
Explicitly decide what belongs in:
- spatial world,
- hybrid UI,
- dense conventional UI.

### RUX-12 — Attention Economy
Measure when notifications/interventions are worth interrupting an engineer.

### RUX-13 — Semantic Zoom
Can one persistent spatial model preserve context from strategic to tool-call level?

### RUX-14 — Counterfactual Organizational Simulation
Can configuration search predict which team/topology will perform best for a mission family?

### RUX-15 — Doctrine Learning
How should successful repeated patterns become versioned doctrine, and when should doctrine expire?

## Candidate benchmarks

1. Find which of 25 active missions needs human attention.
2. Diagnose why an agent is blocked.
3. Assemble a specialist team for a new mission.
4. Identify two teams duplicating work.
5. Determine why a known failure recurred.
6. Compare two team configurations.
7. Find the highest-leverage intervention.
8. Approve/deny consequential actions.
9. Understand a failed mission causally.
10. Retrieve and apply a prior relevant lesson.
11. Reassign a blocked operation to a better team.
12. Explain current contribution to Commander's Intent.

Compare:
- time,
- clicks/gestures,
- navigation changes,
- cognitive load,
- errors,
- missed states,
- operator confidence,
- outcome quality.

## Graduation rule

A world interaction should generally graduate only if it:
- materially improves task completion speed,
- reduces context/navigation switches,
- reduces missed risks/errors,
- improves situation awareness,
- or enables a capability that is difficult in conventional UI.

The world does not need to win code editing, long logs, SQL, giant tables, or exact configuration.
