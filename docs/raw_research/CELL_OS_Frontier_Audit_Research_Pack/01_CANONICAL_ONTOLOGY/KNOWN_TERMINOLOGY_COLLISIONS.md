# Known Terminology Collisions — Audit List

This file should be reviewed before new documentation is promoted to canonical status.

| Current / historical term | Collision | Audit question |
|---|---|---|
| Cell Mesh / CELL Mesh | Used both for an Operative-team topology and for OS-to-OS federation in older material | Reserve Cell Mesh for Operative teams and rename federation? |
| Operative Cell / Cell | Both can denote the bounded deployable mission unit | Is there a real semantic distinction or should one be retired? |
| Organization / Organism | Both can denote persistent collections of Cells | Are they different lifecycle/adaptation concepts or duplicate branding? |
| HyperMESH / A-MESH / T-MESH / etc. | "Mesh" may now imply organizational topology | Rename cognitive/memory sublayers if ambiguity becomes costly? |
| Agent / Operative | Product and technical material may use both | Define Agent as industry baseline and Operative as CELL OS runtime entity? |
| Team / Cell Mesh | User-facing vs technical abstraction | Can nontechnical UI say Team while runtime uses Cell Mesh? |

Rule: terminology should reduce ambiguity, not merely sound distinctive.
