# Start Here — Research Synthesis

This repository contains both a working Agent Factory and a growing research corpus for a broader **Agentic Organization Platform / synthetic-organization operating system**.

## Interpretation hierarchy

Use this order when determining what is true today:

1. runtime behavior and production evidence
2. tests and executable code
3. current source-of-truth snapshot
4. explicit decisions / ADRs
5. current designs
6. research findings
7. exploratory ideas
8. historical/superseded proposals

A detailed research document does not prove that a feature exists.

## Strategic framing

Do not abandon Agent Factory. Treat it as the first production vertical and empirical proving ground for the wider architecture.

A plausible north-star decomposition to investigate — **not a pre-decided architecture** — includes:

- Agent Factory / organization compiler
- organization runtime
- collective cognition / memory fabric
- mission control / ZEUS Agentic IDE
- simulation + evaluation
- evolution / optimization chamber
- research system
- self-maintenance / reliability system

## Required analysis sequence

1. reconstruct the current implementation
2. normalize concepts and terminology
3. map claims to evidence
4. surface contradictions
5. identify decisions already made
6. map research concepts to existing code
7. identify true capability gaps
8. research only decision-blocking gaps
9. compare multiple candidate architectures
10. choose and justify a north-star architecture
11. produce migration and implementation DAG
12. preserve backward compatibility / proving-ground delivery where warranted

## Never assume

- that newer research supersedes older research
- that repeated AI-generated claims are independent validation
- that "novel" means prior-art checked
- that a documented component exists
- that every agentic step should remain agentic
- that the current repository must be renamed
- that a monorepo means client/workload repos must be merged

## Preferred output qualities

The synthesis should be opinionated only after evidence reconciliation. Every major design choice should include alternatives considered, evidence, expected value, implementation cost, risk, eval method and reversibility.
