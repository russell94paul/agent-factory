# Architecture Tournament Prompt

Given the prepared corpus and current codebase, generate **4 materially different candidate architectures** for the next-generation Agent Factory / Agentic Organization Platform.

At minimum include:

1. **Conservative Evolution** — minimum architectural disruption, maximize reuse.
2. **Organization Compiler** — explicit Org-IR, blueprints, organization runtime and shared platform services.
3. **Distributed Cognition / Heterarchy** — topology-flexible organizations, strong knowledge/event fabric, less central hierarchy.
4. **Simplicity Challenger** — deliberately reject sophisticated features unless evidence proves their value.

For each candidate specify:

- core mental model
- entity/topology model
- runtime control plane
- memory/knowledge model
- communication model
- eval/health model
- self-maintenance model
- UI/operator model
- deterministic/agentic boundaries
- migration strategy from current repo
- expected business value
- implementation complexity
- operational complexity
- principal failure modes
- what evidence would make this candidate lose

Score 1-10 with written justification on:

- mission success
- reliability
- auditability/trust
- cost efficiency
- latency
- scalability
- developer productivity
- operator productivity
- extensibility
- maintainability
- self-maintainability
- safety/blast radius
- migration difficulty (reverse score)
- reversibility
- evidence support
- business/client value

Do not select the winner based on feature count or novelty. Prefer the architecture with the best expected outcome-to-complexity ratio under the actual Agent Factory proving-ground requirements.
