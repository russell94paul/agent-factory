# North-Star Roadmap After the Deadline

## Stage 1 — prove the loop

- multiple real agent runs;
- two different workload classes (Marketing reconstruction + Sales bounded patch or connector work);
- structured trajectory/trace;
- reliable evidence and artifact linkage;
- operator-safe auto advancement.

## Stage 2 — make configuration measurable

- complete agent config identity/version dimensions;
- distinguish tunable/declared/measured/derived/policy fields;
- run the same task across configurations/models;
- attach outcomes to exact bindings;
- build eval harness and credit assignment.

## Stage 3 — richer teams

- team presets as data;
- communication/relationship settings only where measurable;
- team-level evals and failure-correlation metrics;
- optional supervisors only when evidence shows benefit.

## Stage 4 — organization representation

Only if real workloads outgrow presets:

- prior-art-aligned organizational metamodel/Org-IR;
- topology as configurable graph;
- typed authority/mandate boundaries;
- evidence/provenance integration;
- command/debugger views.

## Stage 5 — adaptive organization search

- simulations/replay with separated evaluator;
- model-binding-aware candidate archive;
- revalidation cadence;
- quality/diversity only after metrics resist gaming;
- promotion gates before production.

## Stage 6 — bounded self-maintenance

- observe → diagnose → propose → validate externally → quarantine/fallback → human-approved promotion;
- never let the actor silently rewrite its own grader/evidence authority.
