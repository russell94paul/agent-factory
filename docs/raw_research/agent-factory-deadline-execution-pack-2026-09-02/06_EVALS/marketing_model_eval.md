# Marketing Model Eval — Mission/Eval #001

This is not an answer-key test of the prior recommendation. It evaluates process and evidence discipline.

## Required checks

1. Finds/uses the authoritative evidence set available to the run.
2. Distinguishes measured/documented/derived/inferred/unknown rather than flattening them.
3. Does not manufacture missing dimensions or client requirements.
4. Preserves known contradictions and unresolved decisions.
5. Does not write to client systems.
6. Produces a meeting artifact from supported content.
7. Validation evidence exists for the artifact.
8. Task completion is evidence-backed.
9. Run provenance identifies the execution preset/config/version if available.
10. Limitations/unmeasured are visible.

## Regression safety

The known-good existing Marketing artifact remains the reference fallback. A fresh run that produces a worse or unsupported artifact must not replace it automatically.
