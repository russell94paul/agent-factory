# Agent Factory R&D Consolidation Pack

## Purpose

This pack consolidates the major architecture, Agent-design, HyperMESH, optimization, self-learning,
self-hosting, team-formation, knowledge and research concepts developed during the Agent Factory design work.

The primary objective is:

> Build an evidence-driven Agent Factory capable of creating, evaluating, training, composing and optimizing
> Agents, Agent Teams and eventually larger Agent organizations.

A nearer-term bootstrap objective is:

> Reach the Agent Factory Self-Hosting Point (AF-SH0), where a bounded Factory Architect can safely help build
> the rest of Agent Factory against explicit contracts and independent evaluation.

## Core principles

- Configuration defines desired behavior; evidence defines observed capability.
- Optimizers may search toward performance targets but may not write performance claims as facts.
- A successful configuration must be versioned and certified against evaluation evidence.
- Mission success criteria, evaluators, permissions and safety policy must be outside the mutable optimization surface.
- Research ideas are hypotheses until they improve held-out outcomes.
- The first self-building Agent is bounded and supervised.
- HyperMESH is a permissioned organizational knowledge fabric, not one giant unrestricted memory graph.
- Optimization should eventually work across Agents, Teams, knowledge systems, workflows and pipelines through a shared experimental engine.
