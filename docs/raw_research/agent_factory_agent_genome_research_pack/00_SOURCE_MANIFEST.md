## Evidence discipline

For every external mechanism:
1. Find the strongest primary/peer-reviewed source.
2. State what the source actually demonstrates.
3. Separate measured findings from proposed Agent Factory implications.
4. Search for older prior art and synonyms.
5. Propose a falsifiable local experiment before promotion into architecture.
