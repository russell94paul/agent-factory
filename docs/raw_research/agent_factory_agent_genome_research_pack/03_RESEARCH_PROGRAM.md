# Research Program

## P0 — Agent Genome / Configuration Science
Goal: define the canonical AgentDefinition and versioning/certification model.

Deliver:
- field taxonomy;
- genotype vs phenotype vs history vs derived scores;
- schema;
- mutation policy;
- dependency lockfile;
- certification triggers.

## P0 — Evaluation + Benchmark Vault
Goal: make configuration optimization scientifically meaningful.

Deliver:
- mission families;
- held-out sets;
- exact success contracts;
- stochastic repetitions;
- ablations;
- cost/latency normalization;
- leakage controls;
- agent/team/org comparison.

## P0 — Communication / Relationship Science
Goal: represent coordination as measurable configuration and graph edges.

Deliver:
- typed message protocol;
- communication phenotype parameters;
- topology experiments;
- relationship model;
- communication utility metrics;
- compatibility experiments.

## P0 — Monitoring / Observability
Goal: collect phenotype/history without polluting mutable configuration.

Deliver:
- event schema;
- traces;
- run lineage;
- model/skill/tool/config hashes;
- mission outcome mapping;
- team interaction traces.

## P1 — Simulation / Hypertuning
Goal: search agent and team configuration space after evaluation is stable.

Deliver:
- search space;
- optimizer interface;
- multi-objective score;
- quality-diversity archive;
- early stopping;
- shadow promotion.

## P1 — Agent KG Mesh
Goal: join mission, knowledge, capability, communication and relationship state.

Deliver:
- data model comparison;
- graph projections;
- high-value queries;
- event-to-graph pipeline;
- novelty/prior-art analysis.

## P1 — Predeployment Skill-Up
Goal: mission-conditioned readiness improvement.

Deliver:
- readiness vector;
- gap detection;
- bounded skill-up actions;
- micro-evals;
- replace/reinforce decision.

## P2 — Automated Organizational Evolution
Only after:
- eval vault is trustworthy;
- configurations are immutable/versioned;
- shadow replay works;
- policy gates are enforceable;
- optimization leakage controls exist.
