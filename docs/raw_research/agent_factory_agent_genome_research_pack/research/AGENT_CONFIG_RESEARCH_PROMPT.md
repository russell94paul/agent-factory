# Focused Research Prompt — Agent Configuration Science

Investigate how to design a versioned, executable AgentDefinition for Agent Factory.

Compare at minimum:
- Kubernetes spec/status and CRD/controller patterns;
- immutable package/model manifests and lockfiles;
- policy-as-code;
- ML model registries;
- agent frameworks with per-agent config;
- ADAS/AgentSquare;
- modern prompt/program optimizers.

Return:
1. field taxonomy;
2. genotype/phenotype/history/fitness critique;
3. proposed schema;
4. fields safe for auto-tuning;
5. fields that require human/policy control;
6. recertification rules;
7. dependency lockfile;
8. config diff semantics;
9. version promotion lifecycle;
10. 10 experiments.

Explicitly attack the assumption that “more parameters = better.”
