# Focused Research Prompt — Agent/Team/Organization Evaluation

Build an evaluation architecture in which the whole agentic system is the unit of analysis.

Research:
- MASEval;
- MultiAgentBench;
- SILO-BENCH;
- software-agent benchmarks;
- SWE-bench family where relevant;
- OpenTelemetry / agent observability;
- design of experiments;
- causal/credit assignment methods.

Required output:
- benchmark-vault design;
- mission success contracts;
- agent/team/org metrics;
- topology/communication metrics;
- repeated stochastic trial policy;
- held-out/anti-leakage policy;
- credit assignment;
- Pareto scoring;
- promotion gates;
- dashboard metric hierarchy.

Never use raw activity (tokens, messages, tasks) as a primary success metric.
