# Focused Research Prompt — Cross-Domain Transfer to Agent Organizations

Search for architecture/mechanism transfers from:

- Toyota Production System / manufacturing;
- aviation / mission control;
- sports team design;
- biology / immune/nervous systems;
- ecology / swarm intelligence;
- supply chains;
- telecom / congestion control;
- distributed systems;
- cybernetics / Viable System Model;
- incident command;
- organizational psychology/team science;
- mechanism design/markets;
- digital twins;
- statistical process control.

For each candidate:
- original domain;
- canonical name;
- real mechanism;
- evidence;
- Agent Factory mapping;
- which existing concept it overlaps;
- failure mode;
- one falsifiable experiment;
- priority: ADOPT / ADAPT / EXPERIMENT / DEFER / REJECT.

Prioritize mechanisms that improve:
quality, reliability, coordination, knowledge transfer, recovery, or optimization efficiency.
