# Focused Research Prompt — Agent Communication & Relationship Dynamics

Design an Agent Communication Protocol and relationship model for Agent Factory.

Research:
- FIPA ACL/KQML;
- actor systems;
- event buses/pub-sub;
- blackboard/global workspace;
- gossip;
- stigmergy;
- Contract Net;
- MultiAgentBench;
- SILO-BENCH;
- team/crew communication research.

Translate intuitive UI labels such as quiet/loud into measurable parameters:
initiative, frequency, novelty threshold, broadcast threshold, semantic density, verbosity, acknowledgement, escalation, challenge, deference.

Treat “mumbler” as a measurable ambiguity/low-density anti-pattern unless evidence suggests a useful role.

Return:
- message schema;
- performatives;
- topology catalog;
- communication phenotype catalog;
- relationship edge schema;
- metric catalog;
- congestion/backpressure strategy;
- experiments comparing topologies and phenotypes;
- failure modes;
- minimum viable ACP v0.1.
