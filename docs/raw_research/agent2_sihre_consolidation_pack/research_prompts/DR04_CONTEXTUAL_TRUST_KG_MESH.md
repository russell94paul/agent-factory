# DR04 — Contextual Trust, Transactive Memory, and Agent KG Mesh

Research a graph-based organizational cognition system where trust is contextual rather than global.

The graph should connect:

Agent -> Mission -> Context -> Reasoning Topology -> Evidence -> Strategy -> Outcome

and Agent -> Agent relationships such as:
- collaborates_with,
- complements,
- disagrees_productively_with,
- failure_correlated_with,
- trusts,
- delegates_to.

Research:
- transactive memory systems,
- expertise location,
- trust/reputation systems,
- Bayesian trust,
- temporal graphs,
- knowledge provenance,
- graph-based routing,
- collaborative filtering,
- recommender systems,
- social network analysis.

Design:
1. graph schema,
2. contextual trust model,
3. temporal decay,
4. uncertainty in trust,
5. cold-start policy,
6. manipulation/Goodhart resistance,
7. routing queries the graph should answer,
8. evaluation plan.

Avoid anthropomorphic "friendship" fields unless they predict mission outcomes.
