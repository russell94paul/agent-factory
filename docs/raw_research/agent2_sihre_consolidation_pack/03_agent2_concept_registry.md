# Agent 2.0 Concept Registry

This file is the compact registry of proposed architecture concepts.

| Concept | Definition | Primary Mechanism | Agent Factory Benefit | Priority |
|---|---|---|---|---|
| Viable Cognitive Entity (VCE) | Persistent computational entity that maintains and improves its own ability to operate | Self-model + cognition + health + trust + development | Moves beyond task-only agents | P0 research |
| SIHRE Cognitive Kernel | Heterogeneous reasoning governance inside an agent | Routing + trust + uncertainty + verification | Adaptive cognition | P0 |
| Mutable Cognition | Reasoning architecture changes at runtime | Dynamic reasoning graph | Better fit to mission state | P0 |
| Morphological Cognition | Agent constructs different cognitive topologies for different missions | Topology generation and selection | Avoids static planner/reviewer pipelines | P0 |
| Recursive SIHRE | SIHRE principles applied at expert, agent, team, army, and factory levels | Recursive routing and trust | Unified organizational intelligence | P0 research |
| Cognitive Portfolio Optimization | Select experts based on expected utility and error covariance | Portfolio optimization | Diversity with reduced correlated failure | P0 research |
| Cognitive Error Correlation | Measure which agents/experts fail together | Covariance/correlation of failure vectors | Better team composition | P0 |
| Contextual Bayesian Trust | Reliability conditioned on mission context and recency | Bayesian updating | Evidence-based routing and authority | P0 |
| Agent KG Mesh | Graph of agents, knowledge, missions, outcomes, strategies, relationships | Graph memory + transactive memory | Organizational cognition | P0 |
| Transactive Memory | System knows who knows what and who has succeeded where | Expertise-location graph | Faster, better delegation/retrieval | P1 |
| Value of Information | Decide whether more evidence is worth acquiring | Expected utility | Rational research/testing | P0 |
| Expected Verification Value | Decide whether another verifier/test is worth cost | Error probability × impact × detection probability | Selective assurance | P0 |
| Epistemic Metabolism | Measure cognitive resources used to reduce uncertainty / improve utility | Information efficiency | Cost-aware intelligence | P1 |
| Agent Physiology | Operational health vector for cognition/tooling/memory/workload | Homeostatic state | Health-driven behavior | P1 |
| Cognitive Homeostasis | Actively maintain healthy cognitive operating ranges | Model Predictive Control | Graceful adaptation under load | P1 |
| Predictive Cognitive Immunity | Failure memory changes cognition before recurrence | Anomaly signature + memory + policy adaptation | Self-protection | P1 |
| Agent Digital Twin | Model of current agent used for diagnosis/prediction | Digital twin | Safer optimization |
| Counterfactual Self | Simulate alternative agent actions/configs before real action | Scenario simulation | Tail-risk reduction | P1 |
| Dynamic Trust / Earned Autonomy | Authority rises/falls with evidence and risk | Trust policy + capability gates | Safer autonomy | P0 |
| Developmental Agent | Agent progresses through evidence-backed career levels | Certification + mission history | Real experience instead of fictional personas | P1 |
| Emergent Specialization | Factory discovers an agent's actual niche | Performance clustering | Better role design and routing | P1 |
| Dyadic Capability | Agent pair has measurable capability not reducible to individuals | Collaboration analytics | Better pairing |
| Team Emergent Capability | Team performance depends on interaction structure | Interaction effects | Better team architecture |
| Cognitive Genome | Versioned configuration determining cognitive architecture | Genome/config search | Evolvable agents | P1 |
| Agent Phenotype | Observed behavior produced by genome × context × experience | Runtime behavior model | Better evaluation |
| Capability Biodiversity | Diversity of useful specializations and failure modes | Diversity metrics | Avoids organizational monoculture |
| Agent Market | Agents bid for work based on expected success/cost/risk | Market allocation | Dynamic task assignment |
| Stigmergic Coordination | Agents coordinate through changes in shared environment/graph | Digital traces/pheromones | Lower coordination overhead |
| Near-Miss Memory | Successful missions can still produce safety lessons | Weak signal capture | High reliability behavior |
| Graceful Cognitive Degradation | Agent moves through degraded/supervised/safe modes | Runtime state machine | Avoids binary working/failed state |
| Regime Inference | Infer latent operating state of mission/system | HMM/POMDP/state estimator | Context-dependent cognition |
| Tail-Risk-Aware Autonomy | Authority depends on downside tails, not mean performance | CVaR or risk measure | Safer high-impact actions |
| Shapley Cognitive Credit | Attribute outcome contribution to agents/experts | Shapley value | Evidence-backed ranking/promotion |
| Cognitive Genome Evolution | Optimize architecture through controlled mutation/ablation/selection | Multi-objective search | Self-improving architectures |
