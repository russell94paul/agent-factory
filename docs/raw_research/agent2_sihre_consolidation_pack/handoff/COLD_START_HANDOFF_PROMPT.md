# Cold-Start Handoff Prompt

You are joining an ongoing Agent Factory architecture and research project.

Read this entire consolidation pack before proposing new architecture.

## Current direction

The project is exploring a new entity beyond the conventional AI agent.

Working label:

**Agent 2.0 / Viable Cognitive Entity**

The design uses SIHRE — a meta-orchestrated heterogeneous reasoning framework — as a possible cognitive kernel inside each advanced agent.

The main hypotheses are:

1. Reasoning topology should be dynamic rather than a fixed planner/executor/reviewer loop.
2. Experts/agents should be selected by contextual expected utility and correlated failure, not just individual rank.
3. Trust should be contextual, temporal, evidence-backed, and affect routing/authority.
4. Uncertainty should control evidence gathering, verification, abstention, and autonomy.
5. Agent health should be operationalized through homeostatic control.
6. Failure memory should create predictive cognitive immunity.
7. A graph should track agents, missions, strategies, reasoning topologies, relationships, evidence, and outcomes.
8. The agent should maintain a self-model/digital twin for counterfactual testing.
9. Agent specialization and seniority should emerge from evidence.
10. The cognitive architecture itself should be versioned and experimentally optimizable as a "cognitive genome".
11. SIHRE-like governance may recurse across Expert -> Agent -> Team -> Army -> Factory.

## What not to do

- Do not assume the concepts are individually novel.
- Do not call anthropomorphic profile fields architecture.
- Do not optimize only raw success rate.
- Do not assume more agents or more debate improves results.
- Do not propose self-modification without evaluation, lineage, rollback, and recertification.
- Do not invent performance claims.

## Immediate tasks

1. Ground against the current Agent Factory repo/design.
2. Identify what existing components can support this architecture.
3. Identify missing data and evaluation contracts.
4. Prioritize minimal falsifiable experiments.
5. Keep a strict prior-art/novelty boundary.
6. Produce configuration and implementation plans only after the measurement substrate is defined.
