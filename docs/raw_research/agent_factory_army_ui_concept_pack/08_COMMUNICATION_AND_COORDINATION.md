# Communication & Coordination

## Signals channels

### Command Net
Consequential decisions, escalations and direction.

### Tactical Net
Active operation coordination.

### Intelligence Net
Evidence, discoveries, assumptions and research.

### Distress Net
Blockers and requests for help.

### Logistics Net
Tools, environments, compute, credentials and access.

### Direct Comms
Human↔agent or agent↔agent communication.

## Coordination features

### Smart Handoff
Create a compact typed packet:

- objective
- current state
- evidence
- decisions
- unresolved questions
- artifacts
- required authority

### Broadcast Context
Route a finding only to agents/teams whose missions or assumptions are affected.

### Collision Detection
Detect:

- duplicate work
- file overlap
- contradictory decisions
- resource contention
- multiple teams solving the same problem unnecessarily
- downstream team missing an upstream result

### Reinforcement Router
Rank candidates using:

- capability fit
- relevant mission history
- availability
- current workload
- cost
- permission / tenant scope
- recurrence expertise

### Ask Commander
Summarize:

- why behind schedule
- blockers
- duplicated work
- communication gaps
- risk
- recommended reorganization

## Communication health metrics to research

- useful signal / total communication
- response latency
- unresolved distress rate
- duplicate notification rate
- cross-team knowledge reuse
- communication overload
- silent isolated unit rate
- decision propagation latency
