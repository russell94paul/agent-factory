# Evaluation, War Games & Doctrine

## War Games

Controlled champion/challenger evaluation for:

- agents
- prompts
- models
- tools
- team compositions
- formations
- communication protocols
- workflows
- UI interaction models

## Required properties

- frozen evaluation set
- fixed objective
- versioned configuration
- reproducible execution
- outcome metrics
- cost / latency metrics
- regression checks
- human intervention measurement
- provenance

## Doctrine lifecycle

```text
RAW EXPERIENCE
  ↓
AFTER-ACTION REPORT
  ↓
LESSONS LEARNED
  ↓
CANDIDATE DOCTRINE
  ↓
WAR GAME
  ↓
VALIDATED DOCTRINE
  ↓
CERTIFIED / DEPLOYABLE PRESET
```

## Formation examples

### Spearhead
Lead + specialists.

### Recon Screen
Cheap scouts precede expensive execution.

### Swarm
Parallel exploration then synthesis.

### Defensive Ring
Build surrounded by independent review/security/testing.

### Column
Strict sequential execution.

### Double Envelopment
Two independent approaches attack the problem from different directions.

### Reserve Force
Dormant capability activates when defined conditions occur.

## Workflow compression

If agents repeatedly execute the same stable sequence, propose a deterministic composite tool/workflow. This should be evaluated like any other challenger before promotion.
