# Intelligence, Knowledge & Memory

## Distinguish explicit doctrine from historical experience

### Doctrine Library
What the organization intentionally says is true / recommended.

Examples:
- wiki
- procedures
- architecture decisions
- runbooks
- certified operational doctrine

### Intelligence Archive
What the organization has experienced.

Examples:
- missions
- failures
- decisions
- agent traces
- successful fixes
- customer signals
- evaluation outcomes

## Collective Cognition

The platform should be able to:

- publish findings
- retrieve similar missions
- request missing context
- identify contradictions
- track provenance
- apply freshness
- shape retrieval by role/mission
- restructure knowledge around the current operation

## Teach the Army

A learning action should create structured knowledge rather than save a transcript.

Suggested fields:

- claim / lesson
- evidence
- provenance
- applicability
- confidence
- failure family / mission family
- consumers / impacted capabilities
- expiration or review date

## Intelligence Drop

Humans or agents can attach evidence to:

- operation
- squad
- agent
- organizational node
- doctrine candidate
- memory

## Organizational learning diagnostic

For preventable recurrence, trace:

```text
knowledge existed?
  ↓
retrieved?
  ↓
delivered?
  ↓
understood?
  ↓
followed?
  ↓
prevention effective?
```

This turns recurrence into a diagnosis of where the learning loop failed.
