# Concept Evolution & Decisions

## 1. Agentic IDE direction

Initial emphasis: identify buttons/functions for running agents and coordinating teams.

Evolved thesis: build an **Agentic IDE for artificial organizations**, not an agent dashboard.

## 2. Army Base world

Introduced as a playful animated company world for visiting teams, communicating and social presence.

Decision: keep as **secondary/alternative UI**, not the first interface to build.

## 3. Autonomous cross-team lab

Introduced as a persistent lab consuming company-wide learnings, agent successes/failures, customer signals and research to identify highest-leverage changes against success criteria.

Current Army form: **Advanced Projects Command / Black Site**.

## 4. Zeus branding exploration

A complete Greek-mythology mapping was explored for systems, roles and missions.

Decision: for the world UI, move to **extreme Army / Operations Command language** because the terms map more directly to organizational mechanics.

The ZEUS research pack remains useful prior art for interaction and implementation research and is preserved under `prior_research/`.

## 5. Army world optimization

The theme was upgraded from cosmetic gamification to operational compression:

- formations = topology
- supply = context/resources
- radio = communication
- fog = uncertainty
- front line = priority
- tactical zoom = hierarchy

## 6. Service designations

Initial examples used shallow units.

Decision: service designations must support **arbitrarily deep, configurable nesting** via recursive organizational nodes.

## 7. Recurring Failure Rate

User explicitly identified Recurring Failure Rate as tracked metric.

Decision: make RFR first-class and expand into a recurrence/learning suite, including Preventable Recurrence Rate and root-cause classification of organizational learning failures.
