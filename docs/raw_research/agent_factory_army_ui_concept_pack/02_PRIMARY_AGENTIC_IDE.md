# Primary Agentic IDE / Command Console

## Core operator questions

The UI should answer, rapidly:

1. What is happening?
2. What is blocked?
3. Why is it blocked?
4. What needs me?
5. What can the system resolve without me?
6. What changed?
7. Which agents/teams are responsible?
8. What evidence supports the current decision?
9. Is the outcome GREEN?
10. What did we learn?

## High-leverage controls

### Launch Operation
Translate an objective, constraints, budget, permissions and success criteria into an operation.

### Assemble Task Force
Recommend or compile an organization for the operation.

### Build in Parallel
Launch multiple isolated approaches and compare outcomes.

### Fork Strategy
Branch execution while preserving lineage.

### Summon Specialist
Attach the best relevant agent/capability temporarily.

### Broadcast Context
Send a typed evidence/decision packet only to affected units.

### Smart Handoff
Transfer ownership with objective, state, evidence, unresolved questions and artifacts.

### Resolve Collision
Detect overlapping work, contradictory assumptions, resource contention or file conflicts.

### Reorganize Team
Modify topology during execution.

### Ask Commander
Get a synthesized explanation of organizational state rather than reading sessions.

### Red Team This
Spawn an adversarial review organization.

### Convene Council
Independent assessments + disagreement + decision artifact.

### Explain Failure
Causal trace across agent, context, tools, decisions and gates.

### Replay From Here
Counterfactual replay from any state boundary.

### Tournament / War Game
Compare configurations under frozen evaluation.

### Promote Capability
Promote a proven agent/team/workflow to certified doctrine.

### Teach the Army
Convert a finding into structured, provenance-aware reusable knowledge.

### Compile Repetition
Identify repeated stable reasoning/tool sequences and turn them into deterministic tooling.

### Autonomy / ROE Dial
Observe → Recommend → Sandbox → Reversible action → Bounded autonomy.

### Optimize My Organization
Recommend topology/configuration changes from historical outcomes.

## Universal Command Bar

A primary interaction primitive can expose:

- Build this
- Investigate
- Ask team
- Delegate
- Fork approach
- Summon specialist
- Challenge
- Compare alternatives
- Reorganize
- Explain failure
- Replay
- Teach organization
- Evaluate
- Promote
- Roll back

The command is interpreted in the current mission/team/artifact context.
