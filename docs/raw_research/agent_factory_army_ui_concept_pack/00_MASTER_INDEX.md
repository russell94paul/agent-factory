# Master Concept Index

## A. Product / interaction layers

| Concept | Status | Purpose |
|---|---|---|
| Agentic IDE | PRIMARY | Serious engineer operating environment for missions, teams, agents, context, approvals, evals and interventions. |
| Command Console | CURRENT NAME | Army-themed name for the primary Agentic IDE. |
| Army Base / Battlefield View | SECONDARY | Spatial, animated world view over the same operational state. |
| Mission Command | CURRENT WORLD SHELL | Umbrella interaction world for Command Console + Battlefield View. |
| Semantic / Tactical Zoom | CORE | Company → campaign → operation → task force → squad → agent → tool/file without losing context. |
| Spatial Command Language | CORE | Location + zoom + target + formation + gesture carry context so users do less navigation. |

## F. Organizational model

- Arbitrarily nested service designations
- Parent/child organizational nodes rather than fixed hierarchy columns
- Army → Command → Corps → Division → Brigade → Battalion → Company → Platoon → Squad → Agent is only one possible preset
- Custom organizations can use task forces, research cells, experiment teams, etc.
- Each node can own identity, objectives, capabilities, doctrine, resources, performance and health.
- Semantic zoom should compress or expand designation paths automatically.
