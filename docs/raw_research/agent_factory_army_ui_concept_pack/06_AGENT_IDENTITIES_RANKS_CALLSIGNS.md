# Agent Identities, Callsigns, Ranks & Human Roles

## Separate three concepts

Never conflate:

1. **Real organizational authority** — actual role such as CEO, Head of Engineering, EI Lead.
2. **World role / service designation** — e.g. Engineering Command — Commanding Officer.
3. **Gamified experience rank** — progression/achievement, not actual authority.

## Human display example

```text
Jane Smith
Head of Engineering
World role: Engineering Command — Commanding Officer
Experience rank: Colonel IV
```

## Agent display example

```text
RAVEN-17
Reconnaissance Agent
Unit: Intelligence Command / API Brigade / Recon Squad
Rank: Specialist IV
Callsign: Night Owl
Mission record: 128
Specialties: API archaeology, historical retrieval, root-cause analysis
```
