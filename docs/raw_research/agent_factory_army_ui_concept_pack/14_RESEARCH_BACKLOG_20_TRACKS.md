# Research Backlog — 20 Tracks

The original research pack separated highly experimental ideas from business-value-first ideas. Keep that split.

# A. 10 extremely experimental tracks

## E1 — Adaptive Battlefield
Can the world reorganize itself around the current objective, operator role and threat state without disorienting users?

## E2 — Formation Compiler
Can spatially arranging agents be faster and less error-prone than forms/YAML/DAG editing?

## E3 — Fog Intelligence
Can uncertainty be represented spatially so operators recognize unknowns earlier?

## E4 — Ghost Battalion
Overlay similar historical missions/teams as ghost traces over the current operation.

## E5 — Intent Painting
Lasso a region/unit/problem and issue an objective over the selected scope.

## E6 — Cognitive Logistics
Treat context, tools, compute, credentials and memory as visible supply flows.

## E7 — Stigmergic Terrain
Allow repeated successful paths, recurring failures and common handoffs to alter the visual terrain and expose learned organizational patterns.

## E8 — Counterfactual Command Room
Fork an operation into alternate team structures/configurations and simulate outcomes before deploying.

## E9 — Autonomous Staff Officer
Persistent coordination agent predicts what the human commander will need next and prepares options/handoffs, but does not take consequential action outside ROE.

## E10 — Living Headquarters
Humans and agents inhabit a persistent company world supporting cross-team presence, learning and lightweight social interaction.

# B. 10 business-value-first tracks

## B1 — Surveillance / Satellite View
Can one anomaly-only view answer “what needs me?” faster than dashboards?

## B2 — Reinforcement Router
Can expertise/history/availability-based routing outperform manual Slack escalation?

## B3 — Collision Control
Can the system prevent duplicate work, contradictory decisions and overlapping code changes early?

## B4 — Command Authorization
Can approvals across GitHub/workflows/deployments be unified into one governed attention queue?

## B5 — Frontline Optimizer
Can priority placement dynamically reflect objective contribution, blockers, risk and urgency better than static P0/P1?

## B6 — Logistics Health
Can one supply/preflight model diagnose context, access, tooling, compute and upstream readiness?

## B7 — After-Action Learning
Can structured AAR + automatic knowledge extraction reduce recurrence and documentation burden?

## B8 — Workflow Compression
Mine repeated agent tool/reasoning sequences and replace stable patterns with deterministic composite tools.

## B9 — Intelligence Command
Continuously mine company experience/customer signals and rank highest-leverage improvement opportunities.

## B10 — Objective Ledger
Trace each operation/experiment to frozen business success criteria such as revenue, delivery speed, quality or feature adoption.

# Supporting agentic research questions

### Human-swarm command
What macro controls scale from 10 to 100+ agents without O(N) attention?

### Mixed initiative
When should Command act, recommend, ask, wait or escalate?

### Ecological interfaces
Which system constraints should be directly perceptible in a world UI?

### Formation discovery
Do successful mission traces naturally cluster into reusable team topologies?

### Communication optimization
What communication topology minimizes coordination cost without creating information starvation?

### Context logistics
How can context delivery be measured like a supply network?

### Organizational learning
Which interventions actually reduce RFR and PRR?

### Spatial vs dense UI
For which operator tasks does spatial interaction outperform tables, command palettes and graphs?

### Goodhart-safe gamification
Which incentives improve participation without rewarding spam, useless agents, excessive activity or reckless velocity?

### Autonomous organizational improvement
How should Advanced Projects Command search the space of agent/team/process/product changes while avoiding novelty bias and self-confirming experimentation?
