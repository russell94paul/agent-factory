# Research Prompt Pack

These are ready to run in deep-research sessions.

## Prompt 1 — Agentic IDE Interaction Primitives

Research the interaction primitives required for an IDE in which one engineer supervises, coordinates, teaches, reorganizes, evaluates and collaborates with a changing artificial organization. Compare current coding-agent interfaces, workflow tools, human-swarm interfaces, command-and-control systems, RTS interaction models, observability, distributed-systems debugging and collaborative IDEs. Identify primitives that reduce human coordination work rather than simply displaying more agents. Produce a ranked interaction model, benchmark tasks and implementation prerequisites.

## Prompt 2 — Spatial Command Language

Investigate whether spatial interaction can outperform a conventional enterprise UI for supervising multi-agent software operations. Evaluate location as ownership, movement as workflow, formations as topology, fog as uncertainty, supply lines as context/resources, radio as communication, frontline as priority and tactical zoom as hierarchy. Identify where spatial interaction should win, where it should lose, and design controlled user tests.

## Prompt 3 — Human-Swarm Management

Research the best known techniques for one human supervising 10, 50, 100 and 500 autonomous or semi-autonomous agents. Focus on macro-control, exception management, mixed initiative, attention routing, adaptive autonomy, group commands, trust calibration and cognitive load. Translate findings into Agent Factory controls and measurable experiments.

## Prompt 4 — Formation Compiler

Research whether agent-team execution structures can be expressed as reusable visual formations. Mine prior work in multi-agent organizations, workflow DAGs, military staff structures, swarm control and software team topology. Propose a formal Formation IR that can compile into roles, dependencies, communication policies, gates, budgets and escalation rules. Define how historical mission traces could discover new formations automatically.

## Prompt 5 — Context Logistics

Treat agent context, memory, credentials, tools, compute, environment and dependencies as a logistics network. Research how to model supply readiness, deprivation, congestion, staleness and misrouting. Design metrics for context delivery effectiveness and UI concepts that diagnose whether an agent failed because the required supply did not reach it.

## Prompt 6 — Recurring Failure & Organizational Learning

Develop a rigorous Recurring Failure Rate framework for Agent Factory. Distinguish retries, incidents, failure fingerprints, failure families and true recurrence. Define RFR, Post-Fix Recurrence Rate, Preventable Recurrence Rate, Time to Recurrence and Doctrine Effectiveness. Design a causal diagnostic that determines whether recurrence was caused by missing knowledge, failed retrieval, failed communication, prompt/context interpretation, execution or ineffective doctrine.

## Prompt 7 — Advanced Projects Command

Design an autonomous cross-company research and improvement organization that continuously mines agent traces, failures, successes, product usage, customer requests, support signals, costs, architecture and external research. It should rank opportunities against frozen business criteria, generate hypotheses, use a skeptic/red team, prototype in sandboxes, run champion/challenger evaluations and propose Promote/Modify/Kill decisions. Explicitly design anti-Goodhart, anti-novelty-bias and governance controls.

## Prompt 8 — Gamification Without Goodhart

Research gamification for high-skill engineering and remote organizations. Identify mechanics that encourage cross-team communication, ideas, learning and useful contributions without rewarding spam, performative activity, message volume, unnecessary agent use or risky velocity. Develop a metric and reward system based on verified outcomes, learning reuse and cross-team leverage.

## Prompt 9 — Battlefield View Benchmark

Design a study comparing a conventional dense Agentic IDE against a spatial Battlefield View for 12 representative operator tasks: attention routing, locating a blocker, diagnosing missing context, deploying a specialist, detecting duplicate work, understanding a mission topology, identifying uncertainty, approving a consequential action, replaying failure, finding recurring threats, understanding portfolio health and reorganizing a team. Measure completion time, clicks/context switches, errors, missed risks, cognitive load and recall.

## Prompt 10 — Organizational Ontology & Recursive Hierarchy

Design a versioned ontology for arbitrarily nested artificial organizations. Support Army/Command/Corps/Division/Brigade/Battalion/Company/Platoon/Squad/Agent as one preset but allow arbitrary custom levels such as Task Force, Research Cell or Experiment Team. Define inheritance, metrics, permissions, doctrine, resources, mission scope, semantic zoom and service designation rendering.
