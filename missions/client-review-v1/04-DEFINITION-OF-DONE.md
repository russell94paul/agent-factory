# Client Review v1 — Definition of Done

## Must work for the first delivery

- [ ] Client Review opens reliably.
- [ ] At least one real/current project can populate the view.
- [ ] No sensitive/internal-only data leaks into the client view.
- [ ] Overview tells the delivery story in approximately 30 seconds.
- [ ] "What We Understood" is visible.
- [ ] Delivered outcomes are visible.
- [ ] At least one evidence drill-down works end-to-end.
- [ ] Decisions section works.
- [ ] Risks/blockers section works.
- [ ] "What's Next" works.
- [ ] Review / acceptance state is visible.
- [ ] Live Meeting mode works, if feasible without destabilizing the core.
- [ ] Last updated / last verified state is visible.
- [ ] UI survives missing optional data.
- [ ] No obvious broken controls or dead navigation.
- [ ] Existing Agent Factory functionality remains intact.
- [ ] Major client-facing status claims are grounded in actual state/evidence.

## Required quality checks

- [ ] Existing relevant tests pass.
- [ ] New transformation/read-model logic has tests.
- [ ] Missing-data behavior is tested.
- [ ] Client-safe filtering is tested.
- [ ] Evidence references are tested.
- [ ] Decision-state behavior is tested.
- [ ] Presenter journey has been manually exercised at common desktop presentation sizes.

## Nice-to-have only

Cut these if they threaten the core vertical slice:

- animated mission replay;
- live agent visualization;
- generated narration;
- historical time machine;
- project weather;
- synthetic client personas;
- forecasting;
- elaborate cinematic effects.

## Priority rule

Reliability > evidence grounding > client clarity > presentation polish > novelty.
