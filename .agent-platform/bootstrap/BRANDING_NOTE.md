# Branding Boundary

- **Zeus belongs to the user's company project/product family and is not the name of this project.**
- This bootstrap pack uses **Agent Factory** for the existing proving ground and **Agent Army** for the working long-term theme.
- Working optional product names:
  - **Command Forge** — core artificial-organization / operator platform.
  - **Venture Corps** — monetization/opportunity-to-product vertical.
- Architecture, schemas and source packages must not depend on these working names.
- The Army / strategy-game visual theme is intended for the operator UI, with original design and characters rather than copying existing games.
