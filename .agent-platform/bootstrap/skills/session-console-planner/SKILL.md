# Session Console Planner

Prioritize:

1. what is running;
2. what needs human action;
3. blockers/dependencies;
4. artifacts/evidence;
5. reply/resume/pause/cancel where runtime supports it;
6. Synthesis Inbox;
7. truthful status/cost/timing.

Do not fabricate percent-complete unless the underlying workflow has measurable progress units.

Reuse the current UI stack and event APIs where feasible.
