# Working Product Names & Positioning

These are **working project names only, not trademark/domain clearance**. The project is independent of the company's Zeus product family. Preserve the Army / factory / command theme without borrowing Zeus branding.

## Recommended project hierarchy

```text
AGENT ARMY                         umbrella / long-term vision
├── Agent Factory                 existing production proving ground
├── Command Forge                 operator + artificial-organization platform
└── Venture Corps                 opportunity-to-product commercial vertical
```

This hierarchy is intentionally descriptive rather than permanent. Do not rename working code simply to force these labels; use them first in vision/UI/roadmap material and promote names only when useful.

---

## Option A — Command Forge

**Slogan:** **Build the force that builds the software.**

**Positioning:**

The operating platform for assembling, coordinating, observing and improving artificial software organizations. Command Forge turns missions into versioned teams, routes knowledge and communication, executes work through Agent Factory, verifies outcomes, and accumulates reusable organizational capability.

**Best fit:** core platform / Mission Control / organization factory.

**Short description:**

> Give Command Forge a mission. It assembles the right software unit, equips it with relevant experience and tools, coordinates the mission, verifies the result, and remembers what actually worked.

---

## Option B — Venture Corps

**Slogan:** **Research the opportunity. Deploy the team. Compound the win.**

**Positioning:**

A commercial vertical built on Agent Factory and Command Forge. Specialist agents research markets, challenge monetization hypotheses, validate opportunities, assemble temporary product organizations, launch bounded experiments, learn from customers, and feed evidence back into the Factory.

**Best fit:** autonomous micro-SaaS studio, internal venture engine, product portfolio experimentation.

**Short description:**

> Venture Corps turns market hypotheses into evidence-gated software missions: research, validate, build, launch, learn, improve, scale or kill.
