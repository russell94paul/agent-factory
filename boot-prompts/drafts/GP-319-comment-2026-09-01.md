## Design recommendation — no new fact

A conformed cross-channel core fact is **not** recommended, consistent with this ticket's own
2026-08-25 rejection. The rejection cited ~14 copies across 6 schemas; measured, it is 84 objects /
34 names / 7 schemas, so the original reasoning is understated rather than stale. A new fact would
also address roughly **one of ~101 absence-as-zero sites**, all of which live in the dashboard code
where no warehouse structure reaches them.

Recommended instead: keep the fact at its proven grain, add a semantic contract (naming rules +
a definitions register), declare and normalise the `'-1'` sentinel, and repoint the consumer.

   a current wrong number**.
